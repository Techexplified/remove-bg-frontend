# ZeroBG - Background Remover and AI Image Editor

ZeroBG is a powerful Figma plugin that allows you to instantly remove image backgrounds, crop, resize, and apply stunning AI-powered enhancements directly inside your Figma canvas.

## Features

- **Remove Background**: Instantly cut out subjects and remove messy backgrounds with AI-powered precision. Perfect for product shots and portraits.
- **Crop & Resize**: Automatically crop away empty space and center your subject perfectly. Great for e-commerce and social media.
- **Color Background Fill**: Drop your isolated subject onto any solid color or vibrant gradient to match your brand style effortlessly.
- **HD Export**: Export your images in stunning high-definition resolution without losing any fine details.
- **AI Background**: Generate hyper-realistic AI backgrounds tailored perfectly to your subject's lighting and perspective.
- **AI Shadows**: Add realistic, physically accurate drop shadows that ground your subject and create depth.
- **AI Relighting**: Magically change the lighting and mood of your photo to match your new background perfectly.

## Tech Stack
- Frontend: React, Vite, Framer Motion
- Figma Plugin API
- Styling: Custom CSS

## Installation
1. Clone this repository.
2. Run `npm install` to install dependencies.
3. Run `npm run build` to build the plugin UI and logic.
4. Open Figma desktop app, go to Plugins -> Development -> Import plugin from manifest...
5. Select the `manifest.json` file in this directory.
